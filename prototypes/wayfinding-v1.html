A route for every kind of fishing / 三种游玩的同一条路

Choose a way to fish.
Keep the water shared.

This throwaway prototype tests three information architectures for Rise & Reel / 鱼线起落. The copy is intentionally bilingual and follows the locked session, summary, and record vocabulary from the Wayfinder map.

One session model / 一个会话模型Home → setup → fishing session → shared summary.
Three modes / 三类游玩Solo, side by side, or 2D — no winner language.
Local records / 本地记录Each mode keeps its own best and lifetime score.
No account / 无需注册Checkpoint recovery is not a completed record.

A · Harbor Gate / 港口门廊

Invite first, explain second.

Editorial split layout. The primary decision is a welcoming “choose how to fish” moment; the route keeps the rest of the flow legible without turning it into a dashboard.

B · Tide Map / 潮汐地图

Make the whole product visible.

Utility shell with a persistent rail. The mode list is the working surface, while records and settings stay one click away for repeat visitors.

C · Current Flow / 水流引导

Turn the journey into a calm sequence.

Step-by-step flow. The current stage gets the focus; terminology and constraints stay in a narrow side rail so the page never feels like a competitive lobby.

Copy audit / 文案清理

Words to keep, words to retire.

These are deliberate product-language changes, not translation preferences. They protect the shared, replayable promise.

✓
Keep · Session / 会话

Use Fishing Session / 钓鱼会话, Session Summary / 会话总结, and Group Exit / 整组离开.

×
Retire · Match / 比赛

Delete match, timed match, and practice; v1 has one session model.

✓
Keep · Shared-Screen / 同屏

Describe 2–4 independent lanes without implying co-op, versus, a winner, or online multiplayer.

×
Retire · Competition / 竞技

Delete rivals, co-op, leaderboard, standings, and winner language.

✓
Keep · Session Score / 会话得分

Show score, catches, escapes, and best streak. Call retained progress Lifetime Score / 累计得分.

×
Retire · Accuracy / 准确率

Delete accuracy and overlap rate; they add an unnecessary competitive measure.
