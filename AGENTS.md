# Project Instructions

## Product

- Preserve the tactile Stardew-style fishing loop: hold to lift, release to fall, track a moving fish, and maintain overlap to complete a catch.
- Keep gameplay and physics values centralized so playtesting can tune them without rewriting the engine.
- Keep each local player's input, fishing lane, score, catches, and current round independent.
- Design visual components so richer art can replace the first version's CSS visuals without changing the game engine.

## Workflow

- Use Node.js 22 for local development.
- Run tests and a production build before reporting an implementation as complete.
- Do not commit or push changes without explicit user authorization.
